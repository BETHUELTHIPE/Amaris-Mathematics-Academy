# Frontend

Amaris Mathematics Academy public web application and browser-facing tooling.

## Stack

- Next.js / Vinext
- React and TypeScript
- Tailwind CSS
- Supabase Auth
- Cloudflare Workers / D1
- Vite, Lighthouse, Pa11y and Playwright browser checks

## Development

```bash
cd frontend
npm ci
npm run dev
```

## Quality checks

```bash
npm run lint
npm run typecheck
npm run test:unit
npm run build
npm run check:performance
```

Frontend application code, assets, frontend database bindings, migrations, tests, browser tests and frontend scripts are kept inside this folder.
